Perguntas frequentes

O Windows mostrou uma tela azul ("O Windows protegeu o computador"). É seguro?

Sim! O Lumo é um projeto independente e ainda não possui certificado pago da Microsoft (que custa centenas de dólares por ano). Como o código é compilado diretamente pelo GitHub Actions, basta clicar em Mais informações → Executar assim mesmo na primeira instalação.

O Lumo pesa no computador ou derruba FPS em jogos?

Não. Ele é construído em Rust + Tauri (pesa cerca de 3,5 MB no disco), faz cache da leitura de CPU/RAM e entra em repouso no Modo Jogo, mantendo o uso de CPU próximo de 0%.

Como funcionam as atualizações?

O Lumo possui auto-update silencioso assinado criptograficamente. Sempre que sai uma versão nova, ele baixa e aplica sozinho quando você não está jogando ou usando o painel.
